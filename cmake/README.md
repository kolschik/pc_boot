# Набор cmake-файлов для сборки проектов

## Содержимое

**examples** - примеры корневых CMakeLists.txt

**toolchains** - тулчейн файлы для микроконтроллеров

**корневая директория** - .cmake файлы для конфигурирования проекта

## Быстрый старт

```
Примечание: все примеры из этого раздела описывают настройку пустого проекта
```

[В вики проекта](https://gitlab.fsoft.su/flib/cmake/wikis/home) можно почитать о использовании
CMake более подробно.

#### Сборка микропрограммы для МК

1. Подключить данный репозиторий в качестве подмодуля в корень нового проекта.
2. Скопировать в корень нового проекта файл *examples/mcu_example.txt*.
Переименовать этот файл в CMakeLists.txt.
3. Настроить корневой CMakeLists.txt под конкретный МК. 
Изменять можно код под комментариями, которые начинаются с !! 
([подробная инструкция](https://gitlab.fsoft.su/flib/cmake/wikis/manual_mcu)).
4. Создать структуру директорий проекта, описанную 
[здесь](https://devprom.fsoft.su/pm/autopiloting/K-7362).
5. Наслаждаться написанием кода =^_^=

#### Сборка проекта с использованием библиотеки QT

```
Примечание: для сборки проекта на QT подключать этот репозиторий как субмодуль 
не нужно! По крайней мере до тех пор, пока тут висит эта плашка.
```
1. Скопировать в корень проекта файл qt5_example.txt 
(или qt4_example.txt, если проект будет на qt4, очевидно).
2. Переименовать скопированный файл в CMakeLists.txt.
3. Настроить CMakeLists.txt, руководствуясь приведенными там комментариями.
4. Писать код, и радоваться, что сборка работает =^_^=
